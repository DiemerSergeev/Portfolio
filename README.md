# Hi, I'm Dmitrii Sergeev

Embedded Software & Hardware Engineer with approximately 3 years of professional experience in firmware development, from low-level drivers and hardware bring-up to automated measurement systems. M.Sc. in Engineering of Micro- and Nanoelectronics, Peter the Great St. Petersburg Polytechnic University (SPbPU).

I work where hardware meets software: reading schematics and datasheets, writing efficient and maintainable C/C++ firmware, and building reusable architecture that speeds up development. This repository collects my work in both directions.
